# YouTube → Audio Telegram Bot

Бот принимает ссылку на видео с YouTube и присылает в ответ аудиодорожку в формате mp3.
Работает через **локальный Bot API Server**, поэтому лимит на отправку файлов — **2 ГБ** вместо стандартных 50 МБ.

## 1. Получи api_id и api_hash

Локальному серверу нужны реквизиты Telegram-приложения (это не токен бота, а данные для доступа к MTProto API):

1. Зайди на https://my.telegram.org и авторизуйся по своему номеру телефона.
2. Раздел **API development tools** → создай приложение (название и платформу можно указать любые).
3. Получишь `api_id` (число) и `api_hash` (строка) — они нужны только серверу, боту их знать не обязательно.

## 2. Подними локальный Bot API Server

Проще всего через Docker (файл `docker-compose.yml` уже в проекте):

```bash
export TELEGRAM_API_ID=твой_api_id
export TELEGRAM_API_HASH=твой_api_hash
docker compose up -d
```

Сервер поднимется на `http://localhost:8081` — именно на него бот и будет отправлять запросы вместо `api.telegram.org`.

Проверить, что работает:
```bash
docker logs telegram-bot-api
```

> Без Docker: можно собрать `telegram-bot-api` из исходников (https://github.com/tdlib/telegram-bot-api) — потребуется C++ компилятор и сборка через CMake, дольше и сложнее, чем Docker.

## 3. Установи бота

1. Убедись, что установлен Python 3.10+ и **ffmpeg** (нужен для конвертации в mp3):
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - macOS (Homebrew): `brew install ffmpeg`
   - Windows: скачай сборку с https://ffmpeg.org/download.html и добавь в PATH

2. Создай виртуальное окружение и установи зависимости (на новых Debian/Ubuntu системный `pip install` заблокирован — см. `externally-managed-environment`):
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
   Окружение нужно активировать (`source venv/bin/activate`) в каждом новом терминале перед запуском бота.

3. Получи токен бота у [@BotFather](https://t.me/BotFather) (`/newbot`).

4. Скопируй `.env.example` в `.env`, вставь токен (адрес локального сервера уже прописан по умолчанию):
   ```bash
   cp .env.example .env
   # затем отредактируй .env, впиши BOT_TOKEN
   ```

5. Запусти бота:
   ```bash
   python bot.py
   ```

Готово — теперь можно кидать боту ссылки на длинные видео, и лимит 50 МБ не будет мешать.

## Использование

Просто отправь боту в личку или в чат ссылку вида:
- `https://www.youtube.com/watch?v=...`
- `https://youtu.be/...`
- `https://www.youtube.com/shorts/...`

Бот скачает аудио, сконвертирует в mp3 и пришлёт файл.

Все сообщения бота — на украинском.

На любой некорректный ввод (текст без ссылки, видеофайл, документ, фото и т.д.) бот ничего не отвечает — молчит, чтобы не засорять чат.

## Важные ограничения

- **Размер файла**: с локальным сервером лимит — 2 ГБ. Для файлов такого размера убедись, что на диске сервера (том `telegram-bot-api-data`) достаточно места — сервер временно хранит файл при загрузке.
- **Плейлисты**: бот скачивает только само видео, плейлисты игнорируются (`noplaylist: True`).
- **Авторские права**: скачивание и распространение аудио с YouTube может нарушать условия использования YouTube и авторские права правообладателей. Используй бота только для личных целей и контента, на который у тебя есть права (например, собственные видео или контент с открытой лицензией).
- yt-dlp время от времени требует обновления (`pip install -U yt-dlp`), так как YouTube меняет свою защиту.

## Деплой

Для постоянной работы бота можно:
- Запустить на VPS через `systemd` или `screen`/`tmux`
- Обернуть в Docker (добавь `ffmpeg` в образ)
- Использовать webhook вместо polling для продакшена с высокой нагрузкой

## Частые проблемы

**`permission denied` при обращении к Docker socket**
Пользователь не в группе `docker`. Либо запускай команды с `sudo`, либо один раз выполни:
```bash
sudo usermod -aG docker $USER
```
и перелогинься (выйти и зайти заново / перезагрузить систему).

**`externally-managed-environment` при `pip install`**
Новые Debian/Ubuntu блокируют системную установку пакетов. Решение — виртуальное окружение (см. шаг 2 выше в разделе установки бота).

**`ffmpeg and ffprobe not found`**
Видео скачалось, но не смогло сконвертироваться — не установлен `ffmpeg`. Установи (`sudo apt install ffmpeg` или `brew install ffmpeg`) и перезапусти бота. Переустанавливать `venv` при этом не нужно — `ffmpeg` не питоновский пакет, а системная программа.
